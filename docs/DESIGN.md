# 모비체크 v0.1.0 — 자원 소모 중심 설계

## 목적

마비노기 모바일 창 모드 위에 띄우는 수동 숙제 체크리스트. 게임 데이터 접근·자동 조작을 하지 않는다. 은동전과 마족 공물이 상한에 도달하기 전에 소모하고 요일별 숙제를 마무리하는 것이 목적이다.

| 자원 | 갱신 | 상한 | 일일 루틴 |
|---|---|---|---|
| 은동전 | 30분마다 1개, 하루 48개 | 100개 | 룬다에서 필요한 만큼 소모, 보통 40~50개 |
| 마족 공물 | 12시간마다 1개, 하루 2개 | 10개 | 매우 어려움 심층에서 2개 소모 |

일반 던전 1회는 은동전 10개, 더블루팅은 20개 소모한다. 룬다 체크는 고정 횟수가 아니라 다음 날 상한에 막히지 않도록 필요한 만큼 소모했음을 사용자가 확인하는 것이다. 앱은 보유량을 자동으로 알지 못한다.

## 기본 순서

| 요일 | 기본 방문 순서 |
|---|---|
| 월 | 이멘마하 룬다 → 던바튼 주간 정산 → 티르코네일 골드 |
| 화 | 던바튼 보석 → 이멘마하 룬다 |
| 수 | 레이드 TP → 콜헨 레이드·촉매 → 이멘마하 룬다 |
| 목 | 이멘마하 룬다 → 티르코네일 골드 |
| 금 | 던바튼 보석 → 이멘마하 룬다 |
| 토 | 레이드 TP → 콜헨 레이드·촉매 → 어비스 TP·3회 → 이멘마하 룬다·주말 보상 |
| 일 | 이멘마하 룬다 → 선택 던전 → 주말 미완료 확인 |

매일 심층 매우 어려움과 이벤트 확인을 추가한다. 어비스는 0~3 카운터로 추적한다. TP 안내 자체는 체크 항목이 아니다.

## 이동 모델

사용자가 제공한 전체 지도와 설명을 기준으로 **모든 마을 포탈은 다른 모든 마을로 이동 가능**하다. 직선 지역 순서, 실제 시간·비용을 이용한 최단 경로 계산은 하지 않는다.

1. 요일별 기본 순서를 유지한다.
2. 심층이 기본 방문 마을에 있으면 카드에 통합한다.
3. 야외 위치를 선택하면 사용자가 접근 마을을 지정한다. 지도만으로 접근 경로·최단 접근 마을을 추정하지 않는다.
4. 접근 마을이 기존 방문에 있으면 해당 카드에 심층을 통합한다. 간략 보기에서도 실제 심층 위치를 체크 항목에 표시한다.
5. 새 마을 방문이 필요하면 기본 동선의 마지막 확정 마을 뒤, 위치 미확정 콘텐츠 앞에 추가한다. 이는 기본 순서를 유지하는 정책이며 최단 경로 보장이 아니다.
6. 접근 마을 미지정 야외 위치는 별도 카드와 직접 확인 안내로 표시한다. 위치 미설정이면 경고 카드를 표시한다.
7. 일반 마을 이동은 포탈 안내, 레이드는 대기방 입장 후 나가기 안내, 어비스는 실제 클리어 필요 안내를 표시한다.

## 화면

- 상단: 제목·버전·날짜·접기·투명도·닫기.
- 다음 줄: 완료 수치·금주의 심층 위치 드롭다운·적용 버튼. 직접 입력도 가능하다.
- 야외 위치 선택 시: 심층 접근 마을 드롭다운.
- 상세 보기: 자원 안내 버튼, 자세한 이동 설명, 번호·화살표와 체크 카드.
- 하단: 주간 기록·백업·불러오기.
- 간략 보기: 펼치기 버튼, 번호·화살표, 짧은 이동 안내, 체크 카드. 개별 체크 항목을 숨기지 않는다.
- 첫 미완료 카드에 테두리와 `다음` 표시. 완료 후 카드 순서·번호는 유지.
- 체크 행 전체 클릭, 명확한 ✓ 표시, 긴 항목 줄바꿈.
- 내용에 맞는 높이, 화면을 넘으면 카드 영역만 스크롤. 모드 전환은 동일 카드 위젯의 표현을 바꾼다.
- 투명도 버튼 바로 위의 슬라이더 팝업. 상단 공간이 없으면 아래에 표시.

## 수동 자원 계산

선택적인 자원 안내창에서 현재 은동전 0~100개를 입력한다. 현재 시점에 소비하고 이후 24시간 동안 48개가 갱신된다고 가정해 계산한다.

- 상한 100에 도달하지 않도록 목표 잔액은 99 이하.
- 기본 소모 목표 40개, 필요하면 50개.
- 현재 보유량보다 많이 소모하도록 안내하지 않는다. 10개 미만 잔량은 소모 단위에 맞춰 남는다.
- 더블루팅과 일반 횟수를 함께 제시한다.
- 수동 안내일 뿐 실제 게임 보유량·갱신 위상·추가 소비를 추적하지 않는다. 카운터나 체크를 자동 완료하지 않는다.

## 저장

날짜별 고정 숙제 ID, 월요일 기준 주간 심층 위치와 접근 마을, 보기·투명도 설정을 저장한다. 로컬 시각 06:00을 날짜 경계로 사용한다. 원자적 파일 교체와 백업을 적용한다.

이전 지원 형식은 변환하고, 알 수 없는 원본은 그대로 남겨 별도 복구 파일로 새 체크를 저장한다. 정상 체크를 파일 형식 문제 때문에 잠그지 않는다. 복구 파일 자체가 손상된 경우에는 명시적 복구가 필요하다. 저장 실패 시 체크 변경을 되돌리고 오류를 표시한다.

## 검증

요일별 기본 순서, 포탈 안내, 심층 통합·야외 접근 마을·추가 마을 방문, 은동전 0~100개 계산, 실제 마우스 클릭 후 저장·재조회, 06:00 경계와 주간 경계, 반복 보기 전환, 백업·읽기 오류 보호를 검증한다. 실제 Windows 게임 위 표시·DPI·다중 모니터 및 Windows EXE는 별도 검증 대상으로 둔다.
