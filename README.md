# 모비체크 · MobiChecklist v0.1.0

마비노기 모바일 창 모드에서 사용하는 수동 Windows 숙제 체크리스트입니다. 게임 데이터를 읽거나 입력을 자동화하지 않습니다.

새 설계로 구현한 첫 테스트 버전입니다. 이전 구현의 버전 번호를 이어받지 않습니다.

## 실행

Windows / Python 3.10 이상:

```powershell
py -m pip install -r requirements.txt
py main.py
```

화면은 상단 제목·날짜, 완료 수치와 심층 위치 드롭다운, 왼쪽 방문 번호·화살표와 카드, 하단 주간 기록·백업·불러오기로 구성됩니다.

헤더의 빈 공간을 드래그해 이동합니다. `≡`로 간략 보기를 열고 `펼치기`로 상세 보기에 돌아옵니다. 상세 보기의 `◐`를 누르면 버튼 바로 위에 슬라이더만 표시됩니다(화면 위쪽 공간이 부족하면 아래에 표시). 팝업 밖을 누르면 닫힙니다. `×`는 종료입니다.

- 상세 보기: 카드 위에 **금주의 매우 어려움 심층던전 위치**를 설정합니다. 목록에 없는 위치도 직접 입력한 뒤 Enter로 적용할 수 있습니다. 자세한 이동 안내와 진행률도 표시합니다. 하단 **백업** 버튼으로 현재 기록을 원하는 JSON 파일에 내보낼 수 있습니다.
- 간략 보기: 펼치기 버튼과 방문 번호·지역명·체크 항목·카드 사이 순서 화살표만 남습니다. 제목·투명도·닫기·기록 버튼은 숨깁니다. 이동 안내는 `이동 → 이멘마하`처럼 짧게 표시합니다. 체크 항목은 접히지 않습니다. 첫 미완료 카드를 `다음`으로 표시합니다.
- 내용에 맞춰 창 높이를 줄이고, 화면 높이를 넘을 때는 카드 영역만 스크롤합니다.
- 주간 기록에서 날짜를 선택해 수정할 수 있습니다. 과거 날짜의 조회·오늘 복귀는 상세 보기에서 제공합니다.
- 토요일 어비스는 0~3 카운터로 기록합니다.

요일별 숙제 및 상세 동작은 [설계 문서](docs/DESIGN.md)에 있습니다.

## 심층 위치와 동선

같은 방문 지역의 심층 숙제는 카드에 통합합니다. 실제 지도 지역 순서가 확인되지 않은 추가 지역은 기본 동선 뒤에 표시하고 `경유 순서 미확정`을 안내합니다. 최단 경로 계산이 아닙니다. 지역 목록은 예시이며 직접 입력할 수 있습니다. 미설정 경고는 간략 보기에서도 유지됩니다.

## 기록

`%LOCALAPPDATA%\MabiChecklist\state.json`에 자동 저장하고 직전 파일을 `state.json.bak`으로 보관합니다. 로컬 시각 오전 6시를 게임 날짜 경계로 사용합니다. 한국 게임 날짜에 맞추려면 Windows 시간대를 한국으로 설정하세요.

이번 앱은 새 버전의 저장 형식을 사용합니다. 이전 테스트 구현의 `records/settings/deep_weeks` 구조(schema 1 또는 버전 없는 같은 구조)는 한글 숙제명을 고정 ID로 변환해 읽습니다. 어비스 `true`는 3회로 읽습니다. 그 외 형식이나 깨진 파일은 보호하며, 상세 보기의 **기록 불러오기…**에서 지원하는 JSON을 선택하거나 **원본 백업 후 새 기록 시작**으로 새 기록을 시작할 수 있습니다. 임의의 과거 버전 형식까지 지원하는 것은 아닙니다. 최초 원본은 `state.json.original.bak`에 별도로 남깁니다. 저장 실패 시 체크 변경을 되돌리고 오류를 표시합니다.

## EXE 빌드

Windows에서 실행하세요:

```powershell
py -m pip install pyinstaller
py -m PyInstaller --noconfirm --clean --onefile --windowed --name MobiChecklist main.py
```

결과: `dist/MobiChecklist.exe`. 실제 Windows 게임 위 표시, DPI·다중 모니터, EXE 빌드는 별도 검증이 필요합니다. 독점 전체화면에서는 표시되지 않을 수 있습니다.

## 개발 검증

```powershell
py -m unittest discover -s tests -v
```

Linux 클라우드:

```sh
QT_QPA_PLATFORM=offscreen /workspace/.venvs/mobichecklist/bin/python -m unittest discover -s tests -v
```

테스트는 임시 경로에 저장하며 실제 체크 기록을 변경하지 않습니다. 현재 로직 및 Qt 테스트 19개가 통과했습니다. 체크박스는 행 전체(빈 공간 포함)를 클릭할 수 있으며 완료 시 ✓를 표시합니다. 마우스 클릭 후 저장·다시 읽기도 검증합니다. 헤드리스 Qt 검증은 Windows 게임 위 동작 검증을 대신하지 않습니다.

체크 입력이 비활성화되고 기록 오류가 보이면 **불러오기** 또는 **원본 백업 후 새 기록 시작**을 사용하세요. 저장 실패 메시지가 보이면 Windows 저장 폴더의 권한·디스크 공간을 확인하세요. 실패한 체크 변경은 성공한 것처럼 남기지 않습니다.
